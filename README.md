# makeicons

Generate every icon a website needs from a single image. Everything runs in your browser; nothing is uploaded.

## Features

- Favicon (`.ico` and `.svg`), Apple touch icon, PWA icons (standard, maskable and monochrome), web manifest and ready-to-copy HTML tags.
- Works with SVG, PNG, JPG and WebP images.
- Margin, corner radius and background controls with live previews for each icon type.
- Dark mode variant for SVG favicons.
- Basic set by default, a complete set, or pick the files you need.
- Available in English and Spanish.

## Development

```bash
git clone https://github.com/isdamian/makeicons.git
cd makeicons
npm install
npm run dev
```
